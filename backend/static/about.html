Tech Stack

  • Hardware: ESP32-C6 / C5 / C3
  • Backend: Python 3.12, FastAPI, Uvicorn
  • Database: SQLite + SQLAlchemy (async)
  • Frontend: Vanilla HTML/JS/CSS, Chart.js
  • Transport: UART + REST + WebSocket

Data Flow

  • ESP32 captures 802.11 mgmt frames
  • UART sends CSV data to host PC
  • Orchestrator POSTs to /api/ingest
  • Backend stores, detects threats, profiles, and scores
  • WebSocket broadcasts to real-time dashboard UI
